# 07_qaydlar: shaxsiy qaydlaringiz

Bu papkaga Obsidian'da istalgan qaydni yozing. Agent har bir tahlilda bu yerdagi **barcha** `.md` fayllarni o'qiydi.
`_` bilan boshlanadigan fayllar va shu README bundan mustasno.

Nimalarni yozish foydali:
- o'zingizning savdo qoidalaringiz (masalan, "juma kuni NY PM'da savdo qilmayman");
- kuzatuvlaringiz (masalan, "GBPUSD London ochilishida ko'pincha Osiyo low'ini sweep qiladi");
- kurs yoki kitobdan o'z so'zlaringiz bilan yozgan konspektlar;
- bozor bo'yicha haftalik fikrlaringiz.

Qaydlar o'rtasida `[[havola]]` ishlatsangiz, ular Obsidian grafigida bog'lanadi.
