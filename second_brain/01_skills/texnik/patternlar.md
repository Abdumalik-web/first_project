# Skill: Grafik va sham patternlari

**Turi:** texnik

## Grafik patternlar
| Pattern | Turi | Ma'no |
|---|---|---|
| Head & Shoulders | Reversal | Bearish. Neckline teshilganda kuchga kiradi |
| Inverse H&S | Reversal | Bullish |
| Double Top / Bottom | Reversal | Bearish / Bullish |
| Bull / Bear Flag | Continuation | Avvalgi trend davom etadi |
| Ascending Triangle | Continuation | Ko'pincha bullish |
| Descending Triangle | Continuation | Ko'pincha bearish |
| Rising / Falling Wedge | Reversal | Bearish / Bullish |

**Maqsad (target):** odatda pattern balandligi breakout nuqtasidan o'lchab qo'yiladi.

## Sham patternlari
- **Engulfing:** keyingi sham oldingisini to'liq yutadi. Muhim darajada paydo bo'lsa, kuchli reversal belgisi.
- **Hammer / Shooting Star:** uzun soyali sham. Support yoki resistance'da reversal'ni bildiradi.
- **Doji:** bozorda ikkilanish bor.

## Qoida
Pattern faqat **tasdiqlangandan keyin** hisobga olinadi (sham yopilishi va hajm bilan).
Muhim darajadan uzoqda paydo bo'lgan sham patterni kuchsiz signal hisoblanadi.
