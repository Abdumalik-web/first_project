# SMC va ICT: farqi va atamalar mosligi

**SMC (Smart Money Concepts)** ICT g'oyalaridan kelib chiqqan va treyderlar hamjamiyatida
soddalashtirilgan yondashuv. Asosiy farqi shundaki, SMC **struktura qoidalari** (ichki va tashqi struktura,
inducement) va **POI tanlash**ga ko'proq e'tibor beradi. ICT esa **vaqt** (killzone, PO3) va
**PD array**larga ko'proq urg'u beradi.

Agent ikkalasini birga ishlatadi: struktura va POI uchun SMC, vaqt va SMT uchun ICT.

## Atamalar mosligi
| SMC | ICT | Izoh |
|---|---|---|
| BOS | BOS | Bir xil |
| CHoCH | MSS | SMC'da har qanday birinchi teskari buzilish. ICT'da displacement bilan bo'lishi shart |
| Imbalance / FVG | FVG | Bir xil |
| Order Block | Order Block | SMC'da yaroqlilik mezonlari qat'iyroq (`02_poi_order_block.md`) |
| Supply / Demand zone | Bearish / Bullish PD array | |
| POI (Point of Interest) | PD array | Reaksiya kutiladigan zona |
| Liquidity sweep / grab | Stop raid / Judas swing | |
| Inducement (IDM) | (to'g'ridan-to'g'ri muqobili yo'q) | SMC'ning o'ziga xos konsepsiyasi |
| Premium / Discount | Premium / Discount | Bir xil |
